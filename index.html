Cài Đặt Nhanh

1 Tải mã nguồn

git clone https://github.com/Huy-ben/Workshop.git

2 Import database

Mở phpMyAdmin, tạo database workshop_db và import file database.sql

3 Cấu hình

Chỉnh sửa admin/includes/config.php nếu cần

4 Truy cập

Mở http://localhost/Workshop/admin/

Xong! Chỉ mất 5 phút

Cấu Trúc Database

Bảng categories

Trường Kiểu
idINT (PK, AI)
nameVARCHAR(255)
descriptionTEXT
statusENUM
created_atTIMESTAMP
updated_atTIMESTAMP

Bảng products

Trường Kiểu
idINT (PK, AI)
category_idINT (FK)
nameVARCHAR(255)
descriptionTEXT
priceDECIMAL(10,2)
stockINT
imageVARCHAR(255)
statusENUM
created_atTIMESTAMP
updated_atTIMESTAMP
