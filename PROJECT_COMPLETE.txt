───────────────────────────────────────────────────────────────────
USAGE
───────────────────────────────────────────────────────────────────

Installation (5 minutes):
  1. Clone repository
  2. Import database.sql to MySQL
  3. Configure admin/includes/config.php
  4. Access http://localhost/Workshop/admin/

Integration:
  • Copy admin/ folder to your project
  • Include admin/includes/db.php
  • Use helper functions (fetch_all, fetch_single, etc.)
  • See integration-examples.php for examples
